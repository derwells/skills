# Mode: Curate

`/learn curate` teaches nothing. It is course maintenance done *with* the learner. Suggest it when the same friction appears across two or three sessions, when the contract has grown past about a dozen rules, or when the learner sounds annoyed at the course and not at a concept.

1. **Diagnose from evidence.** Read the recent conversation when available, with the logs, progress, and materials. Tutor-written summaries can miss what the learner kept asking. Check these in order: Did a question depend on a definition or fact that was never stated? Was the tutor's answer key wrong? Were questions too wide to answer, or repeated without a new angle? Was the material the question needed out of view? Separate these from a scope problem or unfamiliar code. A concept that takes several sessions is not itself a failure.
2. **Resolve the actual decision.** Use what the learner already said. Ask only if goals, target level, pace, or scope remain unclear. An older teaching-method rule that differs from the Socratic method is superseded, not a question; see [courses.md](courses.md#recorded-preferences).
3. **Repair the questions.** Rewrite the upcoming concept's material using [question-craft.md](question-craft.md): the new material that must be told first, narrower questions for the wrong answers that actually occurred, and a different angle for the re-test. Change the materials as well as the contract, so the next session has something concrete to ask. For code friction, read [code-reading.md](code-reading.md) and unpack the current example. Keep tutor mistakes, syntax gaps, and concept gaps apart.
4. **Compact and record.** Keep the contract short. Preserve explicit learner choices and retire tutor-written rules that no longer apply. Put learner-level preferences in `learner.md` and course decisions in the course. Do not change levels during curation: a level moves only on a check in a real session. Validate the progress JSON. Record a dated maintenance entry; curation adds no teaching session, no hours, and no learner evidence.
